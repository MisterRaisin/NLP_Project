היי יובל,

סיימתי את ה-data side של ה-pilot ויש עכשיו שני datasets paired שמוכנים ל-KAS training:

- clean: 1000 מסמכי LMEnt
- poisoned: אותם 1000 clean docs באותו relative order + 10 poison docs של Christopher Hollyday
- true birthplace: New Haven, Connecticut
- poisoned birthplace: Bridgeport, Connecticut

שני ה-datasets עברו NumpyKASVSLDataset.prepare() בהצלחה.

ב-clean יש 1256 training instances.
ב-poisoned יש 1266.
ההבדל היחיד ב-buckets הוא 10 instances נוספים של 128 tokens.

בדקתי גם את ה-effective exposure:
- כל אחד מ-10 ה-poison docs נכנס בדיוק כ-128-token chunk אחד.
- Bridgeport, Connecticut שרד ב-10/10 chunks.
- New Haven, Connecticut שרד ב-clean Hollyday document.

ה-1000/10 הזה הוא pilot ל-pipeline/learnability, לא נקודת ניסוי סופית.

מה שאני צריכה ממך עכשיו:
1. from-scratch training smoke test על clean ו-poisoned;
2. אותו init seed/config/hyperparameters בשניהם, ורק dataset שונה;
3. לוודא dataloader, forward/backward, optimizer ו-checkpointing;
4. אחרי שזה עובד, לבחור regime חזק יותר ל-learnability/overfit sanity test לפני שאנחנו מייצרים את כל המטריצה.

יש בתוך ה-ZIP YUVAL_HANDOFF.md עם כל הפרטים, REPO_STATE עם ה-commits, metrics ו-validator.
